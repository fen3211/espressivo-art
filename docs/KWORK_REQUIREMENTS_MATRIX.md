## 3. Критические блокеры клиентской демонстрации (Client Demo Blockers)

Для проведения успешной сквозной демонстрации заказчику на Kwork необходимо ликвидировать **8 критических разрывов**:

1. **Разрыв визарда заявки участника (`/dashboard/applications/new`)**:
   - Исправить эндпоинт отправки на `POST /api/applications`.
   - Подгружать реальные CUID номинаций и возрастных категорий активного конкурса `espressivo-vocal-2026`.
   - Передавать обязательный `competitionId`.
2. **Сквозная оплата взноса через тестовый шлюз (`/checkout/mock`)**:
   - Заменить заглушку `alert(...)` на вызов `POST /api/payments/create-session`.
   - Настроить бесшовный редирект в `/checkout/mock?tx=...&appId=...`, где клиент сможет нажать «Подтвердить тестовую оплату» и мгновенно перевести заявку в статус `PAID`.
3. **Реальная выдача PDF-диплома участнику (`/dashboard/certificates`)**:
   - Заменить заглушку `alert(...)` на скачивание файла через `/api/certificates/${applicationId}/download`.
   - Проверить считывание QR-кода камерой смартфона со смарт-страницей `/verify/{token}`.
4. **Устранение ошибки 404 при расчете результатов (`/admin/results`)**:
   - Заменить вызов `/api/admin/results/calculate` на действующий `/api/admin/calculate-results`.
5. **Интеграция выплат преподавателям (`/teacher/payouts` и `/admin/payouts`)**:
   - Связать форму вывода средств учителя с `POST /api/teacher/payouts`.
   - Связать кнопку одобрения администратора с `POST /api/admin/payouts/[id]/confirm`.
6. **Ликвидация моковых массивов в кабинетах**:
   - Заменить `const [applications] = useState(rawData)` в кабинете участника на `fetch('/api/applications')`.
   - Заменить `const students = [...]` в кабинете учителя на `fetch('/api/teacher/dashboard')`.
   - Заменить статические метрики в админке на `fetch('/api/admin/overview')`.
7. **Публикация юридических страниц (Legal Gate)**:
   - Создать маршруты `/terms`, `/privacy`, `/legal/consent` на базе готовых текстов из `docs/legal/` и пролинковать их в футере сайта.
8. **Устранение дефекта приватности в кабинете жюри (`/jury/applications`)**:
   - Удалить клиентский переключатель `blindMode`, раскрывающий реальные имена конкурсантов.
