## 1. Введение и обзор архитектуры

**espressivo ART** — это полнофункциональная цифровая платформа для организации, проведения, слепого судейства и выдачи наградных документов на международных творческих конкурсах для детей и молодежи (5–25 лет).

### Два визуальных мира (Dual Visual Realms)
1. **Публичный портал (`[data-theme="art"]`)**:
   - Стиль *Art+Commerce / Quiet Editorial Gallery* на костяной бумаге (`#e7e7e7`, чернила `#000000`, угольный `#121212`).
   - Академическая эстетика: строгий 0px border-radius, отсутствие теней, шрифты Cormorant Garamond и Akzidenz Grotesk.
   - Доступен на двух языках (переключатель RU / EN в шапке).
2. **Рабочие кабинеты (`[data-theme="cinema"]`)**:
   - Кинематографичный стиль *Frame.io / Midnight Cinema* (`#0a0a13`, акцент Iris Glow `#6199f6`, фиолетовые границы `#4f4f80`, радиус карточек 10px, пилюли 100px).
   - Адаптивное меню: на экранах смартфонов и планшетов (360px–1024px) боковое меню плавно убирается в выдвижной drawer с backdrop blur.

## 2. Быстрый запуск для демонстрации

### Предварительные требования:
- Node.js v18+ (рекомендуется v20+)
- Git

### Команды запуска:
```bash
# 1. Клонирование и переход в ветку демонстрации
git clone https://github.com/fen3211/espressivo-art.git
cd espressivo-art
git checkout feat/kwork-espressivo-demo-readiness

# 2. Установка зависимостей
npm install

# 3. Инициализация базы данных и наполнение реалистичными демо-данными
npx prisma db push
npm run prisma:seed

# 4. Запуск локального сервера разработки
npm run dev
```

После запуска откройте в браузере: **`http://127.0.0.1:5173`**

## 4. Сценарии демонстрации «от А до Я»

### Сценарий 1: Публичный портал и изучение конкурса (Гость)
1. Откройте главную страницу `http://127.0.0.1:5173`.
2. Обратите внимание на:
   - Эдиториальный дизайн без искусственного шума, плавный переключатель **RU / EN**.
   - Четкую сетку взносов: **2 500 ₽ за соло** и **4 500 ₽ за вокальный ансамбль/дуэт**.
   - 4 стандартизированные возрастные группы: **Категория A (5–8 лет), B (9–12 лет), C (13–17 лет), D (18–25 лет)**.
   - Секцию **«Этапы проведения конкурса»** (4 фазы сезона 2026).
   - Интерактивный блок **FAQ** и подвал с действующими ссылками на публичную оферту (`/terms`), политику 152-ФЗ (`/privacy`) и согласие родителя (`/legal/consent`).
3. Перейдите в каталог конкурсов (`/competitions`) и детальную страницу (`/competitions/espressivo-vocal-2026`).

---

### Сценарий 2: Подача заявки и тестовая оплата (Участник / Родитель)
1. Нажмите **«Войти»** и используйте данные `participant@espressivo.art` / `pass1234`.
2. Вы окажетесь в кабинете участника `/dashboard`.
3. Нажмите **«Подать новую заявку»** (`/dashboard/applications/new`):
   - **Шаг 1 (Анкета)**: Введите ФИО участника, дату рождения, исполняемое произведение.
   - **Шаг 2 (Номинация)**: Выберите номинацию (например, *Академический вокал*) и возрастную категорию. Выпадающие списки автоматически синхронизируются с базой данных активного конкурса.
   - **Шаг 3 (Видеозапись)**: Вставьте ссылку на выступление (YouTube, Rutube или VK). Встроенный плеер `ProtectedVideoPlayer` отобразит предпросмотр.
   - **Шаг 4 (152-ФЗ Согласия)**: Проверьте раздельные чекбоксы: согласие на обработку ПДн (ст. 9 152-ФЗ) и согласие на распространение (ст. 10.1 152-ФЗ). Без согласия на обработку переход блокируется.
   - **Шаг 5 (Финализация и оплата)**: Нажмите **«Отправить заявку и перейти к оплате»**.
4. Система автоматически создаст запись в базе данных, сгенерирует криптографическую платежную сессию и мгновенно перенаправит вас на защищенный тестовый шлюз `/checkout/mock`:
   - На экране отобразится карточка с суммой 2 500 ₽, HMAC-SHA256 подписью и кодом заявки.
   - Нажмите **«Подтвердить тестовую оплату (SUCCESS)»**.
   - Серверный вебхук атомарно обновит статус заявки на `PAID`, начислит реферальную комиссию педагогу (+500 ₽) и вернет вас в реестр заявок.

---

### Сценарий 3: Скачивание и QR-проверка диплома (Участник)
1. В кабинете участника перейдите в раздел **«Дипломы»** (`/dashboard/certificates`).
2. Для завершенной заявки (`EXP-2026-1005` Екатерины Вороновой) отобразится наградной бланк *Лауреата I степени*.
3. Нажмите кнопку **«Скачать диплом (PDF)»**:
   - Сервер динамически сгенерирует векторный PDF полиграфического качества с встроенным настоящим QR-кодом (библиотека `pdfkit`).
4. Наведите камеру телефона на QR-код на дипломе (или перейдите по ссылке под QR-кодом):
   - Откроется публичная страница верификации подлинности `/verify/[token]`, подтверждающая официальный статус диплома, имя конкурсанта, баллы и подлинность печати оргкомитета.

---

### Сценарий 4: Партнерская программа и вывод средств (Преподаватель)
1. Выйдите из аккаунта участника и войдите под `teacher@espressivo.art` / `pass1234`.
2. В кабинете преподавателя `/teacher`:
   - Отображается персональный промокод **`TEACHER-MARIA`** и партнерская ссылка с автоматическим копированием.
   - Доступен актуальный баланс комиссий (20% от всех оплат учеников).
   - В реестре учеников отображаются реальные прикрепленные конкурсанты.
3. Перейдите во вкладку **«Выплаты»** (`/teacher/payouts`):
   - Укажите сумму вывода (например, 1 500 ₽) и банковские реквизиты.
   - Нажмите **«Отправить запрос на вывод»**. Баланс атомарно уменьшится, а в журнале создастся запрос в статусе `REQUESTED`.

---

### Сценарий 5: Слепое судейство (Член жюри)
1. Войдите под `jury@espressivo.art` / `pass1234`.
2. Перейдите в очередь судейства (`/jury/applications`):
   - Обратите внимание: **режим «Слепого прослушивания» строго активен**. В таблице отсутствуют фамилии детей, города и школы — отображаются только анонимные коды кандидатов и репертуар.
3. Откройте заявку кандидата (кнопка **«Судейство»**):
   - Терминал воспроизводит аудиотрек через защищенный эндпоинт стриминга `/audio/stream` с поддержкой частичной загрузки HTTP Range (206 Partial Content).
   - Оцените выступление по 4 критериям (Вокальная техника 0–25, Музыкальность 0–25, Артистизм 0–25, Репертуар 0–25) — сумма баллов обновляется на лету.
   - Введите профессиональный педагогический комментарий.
   - Нажмите **«Подтвердить и заблокировать протокол»**. Протокол зафиксируется в базе данных с криптографической временной меткой.

---

### Сценарий 6: Управление и аудит (Администратор)
1. Войдите под `admin@espressivo.art` / `pass1234`.
2. Ознакомьтесь с консолью супер-администратора:
   - `/admin` — сводная статистика по пользователям, заявкам и выручке.
   - `/admin/payouts` — реестр запросов на вывод средств. Найдите заявку преподавателя Смирновой М.А. и нажмите **«Одобрить выплату»**. Статус мгновенно изменится на `APPROVED` с фиксацией в Double-Entry Ledger.
   - `/admin/results` — нажмите **«Рассчитать результаты конкурса»**. Алгоритм рассчитает средние баллы всех участников, определит лауреатские степени и создаст электронные сертификаты с защитными QR-токенами.

## 5. Границы демонстрационного режима (Mock Boundaries)

Для прозрачности и защиты коммерческой тайны заказчика в текущей демонстрационной сборке:

1. **Платежный шлюз**:
   - Функционирует полномасштабная эмуляция эквайринга (`/checkout/mock`) с серверной валидацией HMAC-SHA256 подписи и защитой от race conditions (CAS `updateMany`).
   - Настоящее списание с банковских карт отключено до заключения официального договора интернет-эквайринга (Т-Банк / ЮKassa / Альфа-Банк). В коде предусмотрена строгая блокировка: в production-режиме mock-эквайринг аппаратно заблокирован.
2. **База данных**:
   - В локальном демо-режиме используется SQLite WAL с connection pooling.
   - Для промышленного развертывания (Production) проект готов к переключению на PostgreSQL (достаточно указать `DATABASE_URL="postgresql://..."` в `.env`).
3. **Хранилище видео**:
   - Демо поддерживает YouTube, Rutube, VK Video и локальные стримы. В production-контуре видео загружаются в приватный S3-бакет (Yandex Object Storage / AWS S3) с предсигнированными URL.
