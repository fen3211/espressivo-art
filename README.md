# espressivo ART — International Creative Competition Platform

Полнофункциональный MVP международной конкурсной платформы **espressivo ART** с флагманским творческим конкурсом вокального искусства для детей и молодёжи **«espressivo VOCAL — Young Talents»**.

Архитектура платформы спроектирована и реализована командой специализированных AI-инженеров под руководством главного AI Development Director в строгом соответствии с техническим заданием и двумя независимыми дизайн-системами Refero.

## 2. Реализованный функционал платформы

### 2.1. Публичный портал
- **Главная монография**: Интерактивный лонгрид первого конкурса *espressivo VOCAL — Young Talents*.
- **Разделы**:
  - `/competitions`: Каталог сезонов (Вокал, Фортепиано, Струнные) с фильтрацией.
  - `/competitions/:slug`: Страница конкурса с таймлайном этапов, тарифами и реферальной программой.
  - `/competitions/:slug/nominations`: Сетка 4 номинаций (Академический, Эстрадный, Народный вокал, Хоровое пение) и 4 возрастных категорий.
  - `/competitions/:slug/rules`: Официальный регламент с требованиями к немонтированному видео и критериями.
  - `/jury`: Галерея международного жюри (Вена, Милан, Париж, Санкт-Петербург, Лондон).
  - `/about`: Институциональный манифест культурного фонда.
  - `/login`: Форма входа с авторедиректом и кнопками демонстрационного быстрого входа в 1 клик для всех 4 ролей.
  - `/register`: Регистрация с выбором роли (Участник / Преподаватель) и автоподхватом `?ref=` промокода из URL.
- **Двуязычие**: Мгновенное переключение RU / EN на всех экранах (`LanguageContext`).

### 2.2. Кабинет Участника (`/dashboard/**`)
- Сводка заявок, актуальные статусы жизненного цикла (`DRAFT` → `SUBMITTED` → `PAYMENT_PENDING` → `PAID` → `UNDER_REVIEW` → `EVALUATED` → `COMPLETED`).
- 5-шаговый мастер подачи заявки: данные ребенка, выбор номинации и возрастной группы, прикрепление видеоматериалов с превью, согласия родителей (152-ФЗ / публикация).
- Сохранение черновиков и редактирование до отправки на оплату.
- Просмотр оценок коллегии жюри и рецензий экспертов.
- Галерея наград и скачивание официального полиграфического диплома в формате PDF.

### 2.3. Кабинет Преподавателя (`/teacher/**`)
- **Реферальная программа**: Персональный реферальный код и реферальная ссылка с кнопкой быстрого копирования и QR-кодом.
- **Автоматическое начисление 20%**: Комиссия начисляется исключительно с фактически подтвержденных оплат привлеченных участников.
- **Финансовый реестр (Ledger)**: Двойная бухгалтерия проводок, доступный баланс.
- **Заявки на выплату**: Форма вывода средств на банковские реквизиты/карту с валидацией баланса, проверкой минимальной суммы (1000 ₽) и защитой от параллельного овердрафта.

### 2.4. Кабинет Жюри (`/jury/**`)
- Очередь назначенных заявок с прогрессом оценивания.
- **Режим «Слепое прослушивание» (Blind Audition)**: Полное исключение персональных данных ребенка, родителей, школы и педагога на уровне API (`JuryApplicationProjectionDTO`).
- **Кинематографичный видеотерминал**: Плеер с водяным знаком, 4 независимых слайдера критериев по 25 баллов (Техника, Музыкальность, Артистизм, Сложность репертуара = 100 баллов max), расчет лауреатской степени в реальном времени, текстовая рецензия.
- **Защита от изменений**: Автосохранение черновика и блокировка протокола после финальной сдачи (403 Forbidden).

### 2.5. Административная панель (`/admin/**`)
- Командный центр: KPI выручки, количество заявок, обязательства перед педагогами, статус шлюза.
- Управление пользователями и назначение ролей (Participant, Teacher, Jury, Admin).
- Управление конкурсами, номинациями и возрастными категориями без изменения исходного кода.
- Модерация конкурсных видеоматериалов и матрица назначения экспертов жюри на заявки.
- Автоматический подсчет результатов, нормализация оценок и пакетная генерация лауреатских степеней.
- Бухгалтерский журнал эквайринга и одобрение заявок на выплату преподавателям.

### 2.6. Векторные дипломы высокой печати (PDF)
- Генерация сертификатов через движок `pdfkit` в строгой эстетике Art+Commerce.
- Уникальный регистрационный номер, ФИО лауреата, степень, подписи председателя жюри.
- Криптографический токен и публичная ссылка онлайн-валидации подлинности диплома по QR-коду (`/api/public/verify-certificate/:token`).

### 2.7. Платежный шлюз и защита финансов
- Паттерн `PaymentGatewayInterface` с реализацией `MockPaymentGateway`.
- Криптографическая валидация подписи HMAC-SHA256.
- **Идемпотентность**: Гарантия однократной обработки вебхука (`ALREADY_PROCESSED`), исключающая повторное начисление комиссии преподавателю.
- Защита от race conditions при списании баланса.

## 4. Быстрый старт и локальный запуск

### 4.1. Предварительные требования
- Node.js 18.18+ (рекомендуется Node.js 20+ или 24)
- npm 9+

### 4.2. Установка и запуск

1. Перейдите в каталог проекта:
   ```bash
   cd d:\Projects\espressivo-art
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Инициализируйте базу данных и сгенерируйте Prisma Client:
   ```bash
   npx prisma db push
   ```

4. Заполните базу данных демонстрационными данными (пользователи всех 4 ролей, конкурсы, заявки, оценки, дипломы):
   ```bash
   node prisma/seed.js
   ```

5. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
   Платформа откроется по адресу: **http://localhost:3000**

## 8. Статус реализации функций и ограничения MVP

### 8.1. Полностью работающие функции (Production Ready)
- Полная сессионная аутентификация на HttpOnly cookies с проверкой прав на backend (RBAC).
- Двухмировая изоляция стилей (`theme-art` и `theme-cinema`) без визуального загрязнения.
- Подача заявок с валидацией обязательных согласий родителей (152-ФЗ / GDPR).
- Режим Blind Audition для жюри с гарантированным сокрытием ПДн ребенка.
- 100-балльное оценивание по 4 критериям с фиксацией протокола и блокировкой от изменений.
- Автоматический расчет 20% партнерской комиссии преподавателям по факту оплаты.
- Идемпотентный платежный модуль с защитой от повторных начислений.
- Генерация и скачивание официальных векторных PDF-дипломов высокой печати.
- Публичная верификация подлинности дипломов по уникальному QR-токену.
- Двуязычность (RU / EN) на уровне интерфейсов и системных словарей.

### 8.2. Демонстрационные функции (Mock implementations)
- **Платежный эквайринг**: Реализован через `MockPaymentGateway` со строгой имитацией боевого цикла (генерация ссылки, HMAC-подпись вебхука, проверка идемпотентности). Реальные денежные транзакции не производятся до заключения договора с эквайером.
- **Внешний видеохостинг**: Поддерживаются прямые ссылки на YouTube (Unlisted), Rutube, VK Видео и MP4 cloud. Загрузка тяжелых сырых видеофайлов непосредственно на сервер платформы вынесена в Фазу 2 для снижения нагрузки на сервер.

### 8.3. Подготовленные интеграции для Фазы 2
- Подключение боевых шлюзов эквайринга (ЮKassa / CloudPayments / Prodamus) через уже реализованный интерфейс `PaymentGatewayInterface`.
- Подключение сервисов автоматических выплат самозанятым и физлицам (Solar Staff / Jump.Finance).
- Подключение транзакционной отправки email/SMS уведомлений (Resend / UniSender).
